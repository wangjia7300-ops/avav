# 即梦生图语义转译

把已批准的屏幕规格翻译为即梦能执行的单条中文指令。它是编译器，不是第二个策划器，也不是第二个文案模型。

## 使用前读取

实现或审查转译器时，先读 [即梦转译合同](references/jimeng-semantic-contract.md)。

## 权威输入

- `DetailScreen.copy`：唯一文案真相源。
- `subjectKey` 与产品参考图：唯一主体身份源。
- `scene / shot / composition / proofMethod`：唯一画面任务源。
- `visualInstruction`：只允许补人物/道具动作、光线、材质关注点和视觉风格。
- `negativePrompt`：一条简短约束，最多120字。

兼容字段 `copyFinal` 与 `visualPrompt` 不能覆盖上述权威输入。只要策划文案变化，旧执行稿和旧最终提示词必须判为过期。

## 编译顺序

最终指令固定按以下顺序输出：

1. `主体与任务`：9:16、1440×2560、唯一沟通任务。
2. `参考图身份`：图1锁定产品身份，其余图只补角度和细节。
3. `场景与动作`：策划场景 + 受控视觉增量。
4. `镜头与构图`：策划镜头、构图与证明方式。
5. `定稿文字`：标题、副标题、正文、每条要点和“AI辅助生成”各精确一次。
6. `排版`：移动安全区、文字层级和产品无遮挡。
7. `约束`：单次注入简短约束，禁止额外文字、参数、Logo和水印。

总长度不得超过2000字。不要翻译成英文，不要输出通用负面词库，不要要求无文字底图。

## 视觉增量边界

`visualInstruction` 只能增加：

- 人物或道具的具体动作。
- 光线方向、色温和质感。
- 需要突出的可见材质或局部。
- 不改变任务的摄影/渲染风格。

以下情况必须阻断：

- 忽略参考图、换产品、改款式、改结构或改配色。
- 把已锁定场景换成另一个背景或环境。
- 覆盖本屏任务、镜头、构图、定稿文字或9:16比例。
- 提前写入任何定稿文案，造成最终重复注入。
- 引入 `commercialUse / evidenceIds / claimScope` 等内部字段。

## 输出合同

只返回一条服务端编译的中文 `JimengPrompt`。发送生图 API 前必须用当前 `DetailScreen` 重新编译并逐字比较；不一致时返回过期错误，不调用供应商。

该合同只保证提示词正确。成图后的主体一致性、中文 OCR、遮挡和像素尺寸仍需后验质检，不得冒充已评估。
