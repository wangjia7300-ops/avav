# 即梦转译合同

## 单一真相源

| 信息 | 权威来源 | 模型是否可改 |
|---|---|---|
| 标题、副标题、正文、要点 | `DetailScreen.copy` | 否 |
| 产品主体 | 图1 + `subjectKey` | 否 |
| 场景 | `DetailScreen.scene` | 否 |
| 镜头 | `DetailScreen.shot` | 否 |
| 构图 | `DetailScreen.composition` | 否 |
| 证明方式 | `DetailScreen.proofMethod` | 否 |
| 动作、光线、材质关注点、风格 | `visualInstruction` | 可补充，不可冲突 |
| 约束 | `negativePrompt` | 只注入一次 |

## 正确顺序

```text
主体与任务 → 参考图身份 → 场景与动作 → 镜头与构图
→ 定稿文字 → 排版 → 约束
```

即梦提示词优先明确主体和任务，再描述看得见的画面元素；不要在开头堆放全局规范、全部卖点或长篇解释。

## 污染隔离

- 图1只负责产品身份；其余图只补充侧面、背面和细节。
- 参考图里的旧标题、旧参数线、箭头、角标、人物、食物、道具、背景和旧版式都不是身份信息。
- 视觉增量不能写“换成另一款产品”“背景改为厨房”“忽略参考图”等覆盖语句。
- 定稿文字只在编译阶段注入一次；视觉底稿提前包含原文即为污染。

## 发送前门禁

1. 当前屏证据全部有效且可商用。
2. `copyFinal` 与 `DetailScreen.copy` 一致。
3. 使用当前 `DetailScreen` 重新编译，结果与保存的最终提示词一致。
4. 文案、约束和“AI辅助生成”均精确出现一次。
5. 指令包含场景、镜头、构图、证明方式、9:16和参考图身份规则。
6. 长度不超过2000字；不存在内部字段、英文旧协议或无文字要求。
