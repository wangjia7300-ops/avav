# 文案语义合同

## 三层职责

| 字段 | 回答的问题 | 可写内容 | 禁止内容 |
|---|---|---|---|
| headline | 这跟我有什么关系？ | 用户结果、动作感受、选择结论 | 品名标签、参数清单、内部任务名 |
| subheadline | 为什么成立？ | 本屏甲方事实、参数、材质、结构或功能原意 | 标题复述、空泛形容词、新功效 |
| body | 我在什么场景怎么理解？ | 场景或动作 + 已授权事实 + 克制的用户结果 | 属性堆叠、硬截断、广告口号 |
| keyPoints | 我还要快速核对什么？ | 1–3条直接事实或选择提示 | 另一屏卖点、虚构证言、内部证据语 |

## 事实强度

- 图片原文“易清洗”可转为“饭后好洗不费劲”，但不能扩写为“长效抗菌”。
- 图片原文“轻量级面料”可转为“背着少一点负担”，但不能自行新增克重或减重比例。
- 图片原文为尺寸时，标题写选择意义，副标题原样保留尺寸，正文说明核对场景。
- creative 屏只能写观察、摆放、拿取、搭配和生活节奏，不能暗示新的防滑、耐磨、保温等功效。

## 好文案示例

```text
标题：大小先看清
副标题：直径115mm，高60mm
正文：盛饭盛汤前先把尺寸看明白，选起来更有数。
```

这里标题给结论，副标题给事实，正文给选择动作；事实只出现一次，没有把参数换写成新效果。

## 失败示例

```text
标题：高温淬烧陶土
副标题：采用优质陶土材质
正文：本产品采用高温淬烧工艺，彰显高品质体验。
```

失败原因：标题报工艺，副标题和正文重复；出现说明书腔、广告腔与内部产品视角，用户不知道这跟自己有什么关系。
